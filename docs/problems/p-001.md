# Problem 001 - 복잡한 조건 분기 리팩터링

## 문제 요약

- 중첩 삼항 연산자로 작성된 버튼 상태 로직을 읽기 쉬운 형태로 개선한다.

## 접근

- 첫 시도 아이디어: 삼항 연산자를 유지하되 줄바꿈만 정리한다.
- 고려한 대안: 역할별 컴포넌트 분리, `if` 기반 즉시 실행 함수(IIFE), 정책 객체 사용.
- 최종 선택 근거: 조건이 더 늘어날 가능성이 높아 정책 객체가 확장성과 가독성 균형이 좋다.

## 1차 풀이

```text
const disabled = role === "viewer" ? true : role === "admin" ? false : isTemporary ? true : false;
```

## 최종 풀이 / 해설

```text
const rolePolicy = {
  admin: { canSubmit: true },
  viewer: { canSubmit: false },
};

const canSubmitByRole = rolePolicy[role]?.canSubmit ?? false;
const isSubmitDisabled = !canSubmitByRole || isTemporary;
```

중첩 삼항을 제거하고, 역할 정책과 임시 상태를 분리해 읽기 흐름을 단순화했다.

## 오답 원인

- 한 줄에 조건을 몰아넣어 "코드가 짧으면 좋다"는 착각을 했다.

## 배운 점

- 복잡한 조건은 길이가 아니라 의미 분리 여부가 핵심이다.

## 재도전 조건

- 역할이 4개 이상으로 늘어나는 케이스에서 정책 객체 + 분리 컴포넌트 방식으로 다시 풀기.
